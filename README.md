# Obstacle Assault

**Obstacle Assault** is a 3D platforming game developed using Unreal Engine 5 and C++ as part of the GameDev.tv Unreal Engine 5 C++ game development course.

The project focuses on learning the fundamentals of Unreal Engine gameplay programming, including player movement, obstacle navigation, and C++ integration with the engine.

## Project Overview

- **Engine:** Unreal Engine 5
- **Language:** C++
- **Genre:** 3D Platformer
- **Project Type:** Course-based learning project
- **Course:** Unreal Engine 5 C++ Game Development — GameDev.tv

## Gameplay

Navigate a 3D environment, overcome obstacles, and use player movement mechanics to progress through the level.

## Learning Objectives

This project provided practical experience with:

- Setting up an Unreal Engine C++ project
- Understanding the relationship between C++ classes and Unreal Engine
- Implementing player movement and gameplay logic
- Working with actors, components, and collision
- Building and testing a 3D platforming environment
- Understanding the Unreal Engine development workflow

## Technologies

- Unreal Engine 5
- C++
- Unreal Engine Editor
- Visual Studio
